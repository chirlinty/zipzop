Projeto em destaque

ZipStore — modelagem dimensional de um e-commerce

Projeto acadêmico onde peguei uma base bruta de vendas, cliente e tempo de um e-commerce fictício e construí a camada analítica do zero: schema em estrela, transformação em Power Query e as medidas DAX que alimentam o dashboard abaixo.

Star Schema

DAX — medidas.pbi
Receita Total =
SUM(Fato_Vendas[Valor_Venda])

Receita YoY % =
DIVIDE(
    [Receita Total] -
      CALCULATE(
        [Receita Total],
        SAMEPERIODLASTYEAR(Dim_Tempo[Data])
      ),
    CALCULATE(
      [Receita Total],
      SAMEPERIODLASTYEAR(Dim_Tempo[Data])
    )
)
Power Query — M
let
    Origem = Csv.Document(
      File.Contents("vendas_zipstore.csv")
    ),
    Cabecalho = Table.PromoteHeaders(Origem),
    Tipado = Table.TransformColumnTypes(
      Cabecalho,
      {{"Data", type date},
       {"Valor", type number}}
    ),
    // remove devoluções e testes
    Filtrado = Table.SelectRows(
      Tipado, each [Valor] > 0
    )
in
    Filtrado
